Anki-inspired palette notes

This document records quick palette ideas inspired by Anki's default styling
and popular add-ons. Use as a starting point for designing StudyApp palettes.

Anki characteristics (summary):
- Neutral backgrounds (near-white / near-black) with readable contrast.
- Blue accent color for buttons/controls.
- Subtle borders and slightly desaturated secondary text.

Suggested base tokens (light):
- bg_base: #ffffff
- bg_surface: #f7f7f7
- text_primary: #111213
- text_secondary: #4a4f55
- accent: #2b8cff

Suggested base tokens (dark):
- bg_base: #0f1113
- bg_surface: #151718
- text_primary: #e6e8ec
- text_secondary: #9aa0a6
- accent: #4a90ff

Considerations:
- Avoid high saturation accents for long reading sessions.
- Provide a sepia/paper theme for long-form reading (soft warm background).
- Offer a high-contrast palette for accessibility toggles.

References:
- Manual inspection of Anki's default styles and popular addon palettes informed
  these suggestions; test with real content and iterate on luminance & contrast.
